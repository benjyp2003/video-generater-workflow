# Brand

| Token | Value | Use |
|-------|-------|-----|
| bg | `#0F172A` | backgrounds, thumbnails |
| fg | `#F8FAFC` | text |
| accent | `#38BDF8` | highlights, arrows |
| warn | `#F59E0B` | misconceptions, warnings |
| ok | `#22C55E` | correct / success |
| font-sans | Inter | titles, slides |
| font-mono | JetBrains Mono | code, terminal |

Fonts must be licensed for commercial use (Inter and JetBrains Mono are OFL).

## Thumbnails
- 1280×720, readable at phone size.
- Max 3–4 words of text. One visual subject (a command, a diagram, a logo comparison).
- Dark background, accent colour on the key word.

## Terminal recordings
- Font size ≥ 22 px at 1080p; dark theme; prompt `user@demo:~$`.

# Format structures

Shared modules, different scene structures. `video.yaml: format` selects one.

## concept (6–10 min)
Hook (question) → why it matters → mental model / analogy → step-by-step mechanism
(diagram per step) → short live proof (terminal) → misconception → recap → next.
Required: research, script, diagrams, audio. Optional: terminal demo.
Effort: medium. Automation potential: high (slideshow assembly).

## tutorial (10–15 min)
Goal + result preview → prerequisites (versions!) → steps (terminal per step, why
before how) → verify it works → cleanup → common errors → recap.
Required: sandbox demo, terminal recordings, validation logs. Assembly mostly manual.
Effort: high. Automation potential: medium (VHS tapes make re-recording cheap).

## comparison (6–10 min)
Hook → what each is (one sentence each) → comparison axes table (3–5 axes) → one
diagram per axis → when to choose which → misconception → recap.
Required: comparison table slide, diagrams. Effort: medium. Automation: high.

## architecture (10–15 min)
Hook (one request's journey) → components overview diagram → follow the request
hop by hop (highlight one component per scene) → failure points → recap diagram.
Required: one master diagram + highlighted variants. Effort: high. Automation: high.

## short (≤ 60 s, 1080×1920)
Hook (question, 2 s) → one-sentence answer → one diagram/animation → one example →
"full video" pointer.
Usually cut from an existing long video's verified claims. Effort: low. Automation: high.
